- `.env`와 로컬 비밀 설정

- 학습 체크포인트·대용량 데이터·영상·기타 비코드 파일
- teamwork의 반복 백업 및 Spring Boot 폴더의 그룹웨어 사본: 대표 프로젝트 저장소로 연결

제외된 원본은 로컬에 남아 있습니다. 공개 자료는 전체 환경의 완전한 백업이 아닙니다. 외부 API·DB·데이터·모델 또는 제외된 라이브러리를 사용하는 예제는 재실행 전에 환경을 준비해야 합니다.

## 검증 범위

원본 해시 보존, 반영 파일 수와 사본 해시, JSON·노트북 구조, 출력 제거, 대표 비밀 값 패턴, 추가 문서의 로컬 링크를 확인합니다. 전체 Java·Spring·React 실습의 빌드와 외부 서비스 실행은 일괄 검증하지 않습니다. 기존 학습 코드의 오류나 미완성 예제는 학습 기록으로 유지합니다.
