## 실행과 확인

기본 HTML은 브라우저 또는 정적 서버에서 확인합니다. React 프로젝트는 각각의 `package.json`과 잠금 파일을 기준으로 의존성을 설치하고 scripts를 확인합니다. 외부 API를 사용하는 실습은 개인 키를 설정해야 합니다. 기존 Vite 안내 README는 프로젝트별 원본으로 유지했습니다.

원본은 로컬에 보존되어 있으며 이 저장소는 공개용 정리 사본입니다. 전체 실습의 빌드·서비스 실행은 일괄 검증하지 않았습니다. [자료 반영 기준](../docs/import-report.md)을 참고하세요.
