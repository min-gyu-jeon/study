# PRD: 게시판 글쓰기 화면 개발

## 1. 개요
본 프로젝트는 HTML Form 태그를 활용하여 사용자가 게시글을 작성할 수 있는 인터페이스를 구축하는 것을 목표로 합니다.

## 2. 목표
- 표준 HTML Form 요소를 활용한 데이터 입력 구조 설계.
- 사용자 편의성을 고려한 정렬된 레이아웃 제공.
- 필수 입력 항목 및 유효성 검사를 위한 기본 속성 적용.

## 3. 기능 요구사항

### 3.1. 폼 설정
- **Method:** `POST`
- **Action:** `write.jsp`

### 3.2. 입력 항목 명세
| 항목 | 입력 방식 | 제약 사항 | 비고 |
| :--- | :--- | :--- | :--- |
| 작성자 | `text` | 필수 입력 (`*`) | placeholder 적용 |
| 비밀번호 | `password` | 필수 입력 (`*`) | placeholder 적용 |
| 제목 | `text` | 필수 입력 (`*`) | placeholder 적용 |
| 카테고리 | `select` | 공지사항, 질문, 자유게시판 | 기본값 선택 필요 |
| 공개 여부 | `radio` | 공개 / 비공개 | 하나만 선택 가능 |
| 내용 | `textarea` | 필수 입력 (`*`), 5줄 이상 | placeholder 적용 |
| 첨부파일 | `file` | - | 파일 선택 가능 |
| 작성 동의 | `checkbox` | - | 게시글 등록 동의 |

### 3.3. 버튼 기능
- **등록 버튼:** 입력된 데이터를 `write.jsp`로 전송.
- **취소 버튼:** 입력된 모든 내용을 초기화(reset).

## 4. 화면 설계 및 레이아웃
- **구조화:** `<table>` 태그를 사용하여 항목과 입력 필드를 정렬.
- **레이블링:** 각 입력 항목에 `<label>` 태그를 적용하여 웹 접근성 및 사용성 향상.
- **시각적 표시:** 필수 입력 항목 옆에 `*` 표시를 추가하여 사용자에게 알림.

## 5. 예시 레이아웃
```
게시판 글쓰기

------------------------------------------
작성자 *     [                    ]
비밀번호 *   [                    ]
제목 *       [                    ]
카테고리     [ 자유게시판  v ]
공개 여부     (o) 공개  ( ) 비공개
------------------------------------------
내용 *
[                                        ]
[                                        ]
[                                        ]
------------------------------------------
첨부파일     [ 파일 선택 ]
[ ] 게시글 등록에 동의합니다.
------------------------------------------
             [ 등록 ]  [ 취소 ]
```
