## 실행과 확인

Java 기본 예제는 프로젝트별 `src`를 확인합니다. JDBC·외부 라이브러리를 사용하는 예제는 해당 의존성을 별도로 준비해야 합니다. Java Web은 Servlet/JSP 컨테이너와 DB 설정이 필요합니다.

원본은 로컬에 보존되어 있으며 이 저장소는 공개용 정리 사본입니다. 전체 실습의 빌드·서비스 실행은 일괄 검증하지 않았습니다. [자료 반영 기준](../docs/import-report.md)을 참고하세요.
