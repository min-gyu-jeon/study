## 실행과 확인

각 프로젝트의 `pom.xml` 또는 `build.gradle`을 먼저 확인합니다. Maven 프로젝트는 JDK·Maven 및 필요한 웹 컨테이너를, Gradle 프로젝트는 JDK와 해당 프로젝트의 wrapper를 사용합니다. DB 비밀번호와 JWT 비밀 값은 환경 변수 또는 로컬 설정으로 준비합니다.

원본은 로컬에 보존되어 있으며 이 저장소는 공개용 정리 사본입니다. 전체 실습의 빌드·서비스 실행은 일괄 검증하지 않았습니다. [자료 반영 기준](../docs/import-report.md)을 참고하세요.
