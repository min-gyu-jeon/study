## 실행과 확인

SQL은 내용을 확인한 뒤 학습용 DB에서 순서대로 실행합니다. 계정 생성·DDL·DML은 데이터베이스 상태를 변경합니다. JDBC 예제는 MariaDB 드라이버와 접속 정보가 필요하며 공개 사본의 `CHANGE_ME` 값을 로컬 환경에 맞게 설정합니다.

원본은 로컬에 보존되어 있으며 이 저장소는 공개용 정리 사본입니다. 전체 실습의 빌드·서비스 실행은 일괄 검증하지 않았습니다. [자료 반영 기준](../docs/import-report.md)을 참고하세요.
