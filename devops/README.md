## 실행과 확인

각 실습의 Dockerfile·Compose·run 문서를 확인합니다. 공개 사본의 비밀번호는 치환되어 있어 로컬 환경 변수 설정이 필요합니다. 컨테이너의 포트와 볼륨 설정을 확인한 뒤 실행합니다.

원본은 로컬에 보존되어 있으며 이 저장소는 공개용 정리 사본입니다. 전체 실습의 빌드·서비스 실행은 일괄 검증하지 않았습니다. [자료 반영 기준](../docs/import-report.md)을 참고하세요.
